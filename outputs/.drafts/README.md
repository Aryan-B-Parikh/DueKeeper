# Drafts — ephemeral

This folder holds the verification trail for deep-research runs:

- `*-research-direct.md` — exact search terms + notes
- `*-draft.md` — uncited draft
- `*-cited.md` — cited (becomes `outputs/<slug>.md`)
- `*-verification.md` — FATAL/MAJOR/MINOR review

**Retention:** Keep 7 days after delivery, then `mv` to `outputs/.archive/<YYYY-MM-DD>/` or delete. Finals + provenance in `outputs/` are the permanent record; `cited.md` duplicates the final by design. Do not commit drafts to long-term history — add `outputs/.drafts/` to `.gitignore` if this repo is published.
